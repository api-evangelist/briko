# Briko Robotics

Briko Robotics (Briko Robotica) was a Mexican educational technology startup founded in 2014 in San Luis Potosi, Mexico. It sold a modular programmable electronics kit paired with an online learning platform that taught robotics and programming to children from roughly age eight. The company was accelerated by 500 Startups LatAm (batch 7).

**Status: defunct.** Third-party company databases classify Briko Robotics as deadpooled. Its former domain, `brikorobotics.com`, has been hijacked and now serves unrelated SEO spam — it is deliberately not linked from this profile.

No developer portal, documentation, API, or machine-readable specification was ever published, so this repo carries identity and provenance only. See `apis.yml` for the full enrichment note, including the candidate replacement domains that were checked and ruled out as name collisions.
